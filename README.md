# Healthcare Data Cleaning & Preprocessing

## Overview

This project focuses on cleaning and preprocessing a healthcare dataset containing medical student information. The objective was to improve data quality and prepare the dataset for analysis and machine learning applications.

## Dataset

* Medical Students Dataset
* Contains demographic and healthcare-related attributes
* Includes missing values and categorical features

## Tasks Performed

* Explored dataset structure and statistics
* Identified and handled missing values
* Converted and standardized data types
* Encoded categorical variables
* Cleaned inconsistent records
* Performed basic exploratory data analysis (EDA)
* Created visualizations for data understanding

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Outcomes

* Improved dataset quality and consistency
* Prepared data for analytics and machine learning workflows
* Generated insights through visual analysis

* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Data Visualization
